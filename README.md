# Mi Web para Práctica de Kubernetes

Página web estática mínima lista para construir con Docker y desplegar en Kubernetes.

## Contenido

- `index.html`: Página web básica lista para usar.
- `Dockerfile`: Servidor Nginx ligero (Alpine) para contenerizarla.
